# Angle 3 — Image Guide: Mid-career Financial Confidence Gap

**Design Principle:** This audience (28–42) is digitally literate, ad-savvy, and has seen every type of financial marketing. Creatives must feel like smart content they'd save and share — not a traditional FA ad. Bold, data-forward, editorial. Think LinkedIn posts, not insurance brochures.

**Platform specs:**
- Feed: 1080x1080px (square) or 1080x1350px (portrait — recommended)
- Stories/Reels: 1080x1920px
- Link ad: 1200x628px

---

## Creative Concept 1 — Variant A (60% Stat Card)
**Emotional Direction:** Identity validation — "You are not alone"

**Image Description:**
Pure typography on dark background. No photos. Looks like a thought-leadership Instagram post that could go viral. The goal is scroll-stopping with a single number.

**Layout:**
```
┌────────────────────────────────────────────┐
│                                              │
│                                              │
│                  60%                         │
│                                              │
│   of Singapore workers live paycheck        │
│   to paycheck in 2024.                       │
│                                              │
│   (ADP People at Work 2025)                  │
│                                              │
│   ─────────────────────────────             │
│                                              │
│   What's your plan to not be one of them?  │
│                                              │
│   Free Freedom Number Audit →               │
│                                              │
└────────────────────────────────────────────┘
```

**Colour Palette:**
- Background: Deep charcoal (#1C1C2E)
- "60%" — Electric teal (#06D6A0), very large (120pt+)
- Body text — White (#FFFFFF), 18–22pt
- Source citation — Grey (#9CA3AF), 12pt
- Divider line — Amber (#F4A261), 1px
- CTA — Teal (#06D6A0), 14pt

**Typography:**
- "60%" — Bebas Neue or Montserrat ExtraBold, no leading
- Everything else — Inter Regular or Poppins

**Canva Build Instructions:**
1. Dark charcoal canvas (1080x1350px)
2. "60%" text element: full-width, centred, teal, massive
3. Subtext: white, 18pt, max 4 lines
4. Citation: grey, 12pt
5. Thin amber horizontal rule divider
6. CTA text below: teal

**AI image:** Not needed — pure typography

**Colour Palette:**

**Canva Build Instructions:**

3. Red rectangle (line) overlaid at slight angle as strikethrough
4. Body text below
5. Small teal-bordered box with the T. Rowe Price stat

## Creative Concept 3 — Variant C (Burnout Reel)
**Emotional Direction:** Pain recognition + Hope + Urgency

**Format:** This works best as a short video Reel (15s) or an animated text card sequence. Can also be static if video is too complex.

**Text Card Sequence (15 seconds):**

| Frame | Duration | Text | Design |
|-------|----------|------|--------|
| 1 | 3s | "Working harder than ever." | White text, dark BG |
| 2 | 3s | "Still feel financially behind." | White text, dark BG, slow fade |
| 3 | 3s | "Under-40s in Singapore are 3x more likely to be extremely burnt out." | Teal stat text |
| 4 | 3s | "Most of them don't have a number." | Amber text, bold |
| 5 | 3s | "Find yours free → Freedom Number Audit" | CTA, teal + arrow |

**Audio:** Lo-fi background beat, minimal. Or no audio (many people watch on mute).

**Canva Video Build:**
1. Use "Video" mode in Canva
2. 5 text card "pages" with auto-play transitions
3. Each page: 3 seconds display
4. Transitions: Simple fade or cut (no animations — keeps it clean)
5. Export as MP4, upload to Facebook as video ad

**Static alternative (if video feels complex):**
- Single dark image with the "3x" stat large + "What most don't have... is a number." + CTA
- Run as 1080x1350 static image in feed

## A/B Testing Priority for Angle 3 Creatives

| Creative | Format | Test Against | Success Metric |
|----------|--------|-------------|----------------|
| 60% stat card (Variant A) | 1080x1350 static | Run first as control | CPL |
| Burnout Reel (Variant C) | 15s video | Test vs Variant A | CPL + lead quality |
| $1M Myth (Variant B) | 1080x1350 static | Test after A/C | Lead quality (higher CPL expected) |
| Cost of Living (Variant D) | 1080x1080 static | Secondary test | Engagement rate |

**Golden rule:** Run at minimum 2 variants at all times. Kill anything with CPL >3x your best performer after 500+ impressions per variant.

## Cross-Campaign Brand Consistency Notes

While Angle 3 has a distinctly different visual language from Angles 1 and 2, maintain these consistent elements:

- **Logo placement:** Bottom right, same proportional size across all campaigns
- **Disclaimer text:** Same wording, same small grey font, always present
- **Your name:** Visible in every creative (builds personal brand recognition)
- **WhatsApp number:** Included on all image creatives where space allows
- **CTA arrow style:** Consistent "→" or ">" treatment across all angles

The visual differentiation (warm/soft for Angle 1 vs authoritative for Angle 2 vs bold/modern for Angle 3) is intentional. Audiences who see multiple campaigns will not perceive it as inconsistent — they'll subconsciously recognise the range of situations you cover.
